# How to Enable Crosshair and Trackball in Blazor Charts

## Overview

This sample demonstrates how to enable and customize crosshair and trackball functionality in the Syncfusion [Blazor Chart](https://www.syncfusion.com/blazor-components/blazor-charts) component. The application shows how users can inspect chart data interactively by moving the pointer across chart series and viewing contextual information through crosshair and trackball elements. The sample also includes crosshair tooltip customization, allowing developers to tailor the display of chart data during user interaction.

The project serves as a reference implementation for adding advanced chart navigation and data-inspection features to Syncfusion Blazor Charts.

## Key Features

- Demonstrates crosshair functionality in Syncfusion Blazor Charts.
- Demonstrates trackball behavior for inspecting chart data points.
- Shows how crosshair tooltips can be displayed during chart interaction.
- Includes customization of crosshair tooltip content and appearance.
- Demonstrates interactive chart navigation through pointer movement.
- Uses Syncfusion Chart crosshair and trackball features to improve data inspection.
- Provides chart interaction scenarios that help users analyze chart values without permanently displaying labels.
- Implements crosshair and trackball rendering within a Blazor chart application.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Open `CrosshairandTrackball.sln`.
3. Restore all NuGet packages.
4. Set the `CrosshairandTrackball` project as the startup project if required.
5. Build the solution.
6. Run the application using `Ctrl+F5`.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the folder containing `CrosshairandTrackball.csproj`.

```bash
dotnet restore
dotnet run
```

4. Open the local application URL displayed after the application starts.

# How to Enable Crosshair and Trackball in Blazor Charts

This sample project demonstrates how to add **crosshair** and **trackball** functionalities to **Syncfusion Blazor Charts**. It focuses on enhancing data visualization by enabling interactive chart elements that help users track data points more precisely. The project also includes a practical example of **customizing the crosshair tooltip** to display meaningful information when hovering over chart data points.

The implementation is intended for developers who are working with Blazor and want to improve chart interactivity using Syncfusion’s charting components. By running this sample, you can understand how crosshair lines and trackball behavior work together to improve the readability and usability of data-driven applications.

## Key Features

- Enable crosshair support for precise data point tracking
- Add trackball functionality to view grouped data values
- Customize crosshair tooltip appearance and content
- Demonstrates usage within a Blazor application
- Uses Syncfusion Blazor Charts components

## Prerequisites

To run this sample, ensure the following requirements are met:

- Visual Studio 2022 installed
- .NET SDK compatible with Blazor projects
- Basic understanding of Blazor and C#

## How to Run the Project

Follow these steps to run the sample locally:

1. Clone or download this repository to your local machine.
2. Open the solution file using **Visual Studio 2022**.
3. Restore the required NuGet packages by rebuilding the solution.
4. Run the project using the debugger or without debugging.
5. Open the application in your browser to view the chart with crosshair and trackball enabled.

## Usage

Once the project is running, interact with the chart by hovering over data points. The crosshair will align along the axes, and the trackball will display tooltip information for relevant data points, allowing easier comparison and analysis.
